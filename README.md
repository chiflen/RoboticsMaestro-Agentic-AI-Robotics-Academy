# RoboticsMaestro Agentic AI & Robotics Academy
**Three-level, project-based curriculum | Foundation → Intermediate → Advanced**

An original, GitHub-ready training package for AI engineering, AI coding assistants, agentic systems, cloud AI platforms, and simulation-first robotics. Inspired by the *structure* of comprehensive public learning repositories, but the content here is independently authored.

## What is included
- Interactive `index.html` course portal with search, level filter and local progress tracking.
- 18-week teaching plan, level outcomes, lesson template and facilitator guide.
- Labs for prompt testing, safe tools, RAG evaluation, workflow agents, red-teaming and robot state machines.
- Three capstone briefs, hackathon playbook, quiz bank and answer key, assessment rubrics.
- Tool landscape covering GitHub Copilot, Claude Code, Claude Cowork (where available), Azure AI Foundry, Amazon Bedrock, Google Vertex AI, OpenAI API concepts, MCP, LangGraph, Docker, GitHub Actions, ROS 2, Gazebo and OpenCV.
- Responsible AI/robotics, cloud cost, secrets and security guidance.
- GitHub Pages workflow and contribution instructions.

## Run locally
Open `index.html` in a browser. For Python labs, use Python 3.11+ and install optional dependencies with `pip install -r requirements.txt`. Tests: `pytest`.

## Publish on GitHub
1. Create a repository and upload these files.
2. Push to branch `main`.
3. In GitHub, enable Pages if needed; the included workflow publishes the root directory.
4. Keep `.env` and credentials out of Git. Cloud labs are optional and may incur charges.

## Delivery
18 weeks, two 90-minute sessions per week, plus 2–4 hours of independent practice. Each six-week block ends with a level capstone. Final week is a team hackathon and technical defense.

## Safety and limitations
This is a learning curriculum, not an accredited degree or vendor certification. Model/provider features change; verify official docs before a cohort. Simulation does not certify robot safety. No real robot actuation without qualified supervision, risk assessment, manufacturer guidance, and independent safety controls.
