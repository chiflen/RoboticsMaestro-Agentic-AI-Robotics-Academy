# Level 3 Capstone — Production-Minded Agentic System
Solve a bounded user problem with an evaluated agent workflow or simulation-first Physical AI.

Required: user problem and success metric; architecture diagram and two ADRs; separation of model, deterministic logic and tools; tests and repeatable evaluation; CI; secrets/data plan; threat model; rollback/incident plan; cost estimate; human approval/audit; accessibility; demo and technical defense.

Stretch: justified multi-agent design, provider benchmark, MCP-compatible tools, ROS 2/Gazebo integration, telemetry dashboard or fault injection. A working demo alone is insufficient; show reproducibility, safe failure behavior and limits.
