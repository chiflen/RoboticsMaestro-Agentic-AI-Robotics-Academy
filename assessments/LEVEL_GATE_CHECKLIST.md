# Level Gate Checklist
## Foundation
- [ ] Prompt test matrix and uncertainty handling
- [ ] Git pull request with reviewed AI-generated code
- [ ] Tested Python helper and validated tool
- [ ] Simulation state machine and limitations
## Intermediate
- [ ] Source-aware retrieval and abstention
- [ ] Validated least-privilege tools
- [ ] Idempotent workflow and approval log
- [ ] 20-case evaluation and injection test
## Advanced
- [ ] Multi-agent design justified against simpler baseline
- [ ] CI and dependency review
- [ ] Threat model and rollback plan
- [ ] Cost/latency/task success evidence
- [ ] Technical defense and safety review
