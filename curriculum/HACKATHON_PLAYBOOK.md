# Hackathon Playbook
Recommended 24–48 hours; teams of 2–5. One-day format can use starter code and mock services. Do not use real customer data or connect prototypes to unsupervised physical robot actuation.

## Challenge themes
1. Community knowledge navigator with citations and safe abstention.
2. AI business operating partner: lead intake, qualification, CRM mock and human-approved follow-up.
3. Robotics maintenance assistant over simulated telemetry.
4. Multicloud model evaluator comparing task success, latency, cost and controls.
5. AI learning coach with transparent adaptation and privacy protections.
6. Smart facility digital twin using simulated sensors.
7. Accessible multimodal assistant with uncertainty communication.
8. Agent security challenge that detects prompt injection and unauthorized tool use.

## Deliverables
Repository, 3-minute demo, README, architecture diagram, tests/evaluation, threat model, privacy note, limitations, cost estimate, user story, success metrics and contribution statement.

## Judging rubric (100)
User value 15; functionality 15; evaluation evidence 15; engineering quality 15; safety/security 15; technical depth 10; accessibility 5; business/impact 5; demo/teamwork 5.

## Disqualifiers
Exposed secrets, unauthorized data, unsafe physical actuation, deceptive claims, fabricated results or unreviewed harmful external actions.
