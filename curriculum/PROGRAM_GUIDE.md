# Program Guide

## Learning design
RoboticsMaestro teaches **understand → design → build → test → secure → deploy → measure → improve**. Learners must show evidence, not simply produce an impressive model response.

| Level | Weeks | Outcomes | Capstone |
|---|---|---|---|
| Foundation | 1–6 | AI literacy, Git, AI-assisted coding, prompts, Python/APIs, bounded tools, robotics state machines | AI helper + tested simulation |
| Intermediate | 7–12 | RAG, tool use/MCP concepts, stateful workflows, evaluation, cloud comparison, ROS 2 simulation | Grounded operations agent or telemetry assistant |
| Advanced | 13–18 | Multi-agent architecture, CI/CD, security, reliability, Physical AI, research and commercialization | Evaluated system + safety case + defense |

## Weekly rhythm
1. Explore a user problem and success metric.
2. Explain the core concept and failure modes.
3. Instructor demonstration.
4. Guided build.
5. Test normal, edge and adversarial cases.
6. Submit evidence and reflect.

## Assessment
Knowledge checks 10%; labs/tests 20%; architecture/security reviews 15%; project evidence 25%; demo/technical defense 20%; reflection/teamwork 10%. Suggested pass is 70%, with no unresolved critical safety or security failure.

## Required evidence
GitHub repository; README/setup instructions; tests and results; architecture diagram; one architecture decision record; evaluation data; security/privacy notes; demo; individual reflection.

## Access and inclusion
Use captions, transcripts, plain-language summaries, screen-reader-friendly structure and low-bandwidth alternatives. Paid cloud accounts are not required to pass core objectives.
