# 18-Week Teaching Plan
## Foundation
1. **AI and engineering foundations** — tokens, context, model limitations, uncertainty, responsible use, repo setup. Build an AI glossary and evidence-based README.
2. **GitHub and AI-assisted development** — branches, pull requests, GitHub Copilot, Claude Code, code review and testing. Submit a reviewed pull request.
3. **Prompt/context engineering** — schemas, examples, constraints, test matrices. Test at least 10 cases.
4. **Python, APIs and data** — modules, JSON, HTTP, errors, environment variables. Build a validated helper API.
5. **First AI app and bounded agent** — model adapter, deterministic tools, approval gates. Build mock support assistant.
6. **Robotics foundations** — sensors, actuators, state machines, simulator-first work. Level 1 capstone.

## Intermediate
7. **RAG and knowledge systems** — chunking, retrieval, metadata, citations and abstention. Evaluate 20 questions.
8. **Tools, function calling and MCP concepts** — schemas, least privilege, validation, timeouts. Add mock search/calculator/CRM tools.
9. **Stateful workflows** — routing, retries, idempotency, human review. Build lead qualification workflow that drafts but does not send outreach.
10. **Evaluation and observability** — task success, groundedness, traces, latency and cost. Build regression harness.
11. **Cloud AI platforms** — Azure AI Foundry, Amazon Bedrock, Google Vertex AI and portable adapters. Submit decision matrix.
12. **ROS 2 and perception simulation** — nodes/topics, telemetry and perception/action boundaries. Level 2 capstone.

## Advanced
13. **Multi-agent systems** — supervisor/specialist patterns, state, handoffs. Compare with a single-agent baseline.
14. **Production engineering** — containers, CI/CD, secrets, rollback. Add CI workflow and dependency checks.
15. **Security and reliability** — prompt injection, data leakage, tool abuse, budgets and provider failure. Red-team capstone.
16. **Physical AI and digital twins** — sim-to-real gap, sensors, telemetry, safe stop and supervision.
17. **Research and commercialization** — hypotheses, baselines, user validation, privacy/IP, operating costs.
18. **Hackathon and technical defense** — build, test, demo, defend, judge and retrospect.
